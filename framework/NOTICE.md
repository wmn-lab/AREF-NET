# Framework notice

The files under `framework/patch/ultralytics/` are a selective source patch
from the YOLOMM-enabled Ultralytics framework used by AREF-NET. The patch is
provided to make the custom multimodal integration easier to obtain; it is not
a replacement for the complete upstream framework.

Obtain the upstream `v8.3.163` source separately and retain its license and
attribution files. Review the applicable upstream license before redistribution.
